# Additional Project Summaries

## Hosting and web operations

Built and maintained Linux-hosted web services using Ubuntu, Debian, Plesk, Nginx and PHP-based platforms. Work has included DNS configuration, TLS certificates, reverse proxying, application deployment, permissions, mail-flow troubleshooting and service migration.

**Evidence demonstrated:** Linux administration, web infrastructure, DNS, TLS, troubleshooting and customer-focused service support.

## VoIP and PBX environments

Configured and supported 3CX and FreePBX-based environments, including extensions, SIP registration, trunks, inbound and outbound routing, endpoint configuration and investigation of registration or call-flow faults.

**Evidence demonstrated:** SIP fundamentals, layered troubleshooting, firewall awareness, documentation and communications-platform support.

## Private cloud and file services

Deployed and administered private cloud and storage services using Nextcloud, Synology and TrueNAS concepts. Work has included storage integration, access permissions, reverse proxying, certificates, backup planning and service maintenance.

**Evidence demonstrated:** application operations, storage, identity and access thinking, recoverability and Linux support.

## Monitoring and operational tooling

Worked with monitoring agents and availability checks to identify service and network failures. The focus is on useful checks that represent actual service health rather than producing alerts without operational value.

**Evidence demonstrated:** observability, incident response, dependency analysis and continuous improvement.

## Self-hosted application deployment

Deployed services through Docker, Portainer, LXC containers and conventional Linux virtual machines. Typical tasks include environment configuration, persistent storage, reverse proxying, upgrades and log-based diagnosis.

**Evidence demonstrated:** container operations, Linux, application dependencies and change management.

## Networking and remote access

Configured managed networks using MikroTik and UniFi platforms, including VLANs, DNS forwarding, policy routing and WireGuard VPN access.

**Evidence demonstrated:** network segmentation, routing, secure remote access and fault isolation.

## Web and software projects

Created and supported WordPress, PHP and API-backed web projects, including a FastAPI-based service and Android application concepts using Retrofit and Room for offline data.

**Evidence demonstrated:** understanding of application architecture, APIs, web deployment and the relationship between development and operations.
